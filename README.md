# 🧪 작업형3 통계 실습실

빅데이터분석기사 실기 **작업형3**(가설검정 · 분산분석 · 카이제곱 검정 · 회귀 · 로지스틱 회귀)을
**설치 없이 브라우저 안의 진짜 파이썬**(scipy · statsmodels · pandas)으로 연습하는 실습실입니다.
통계를 처음 배우는 사람을 위해 「쉽게 말하면」 설명과 눈으로 보는 그림 도구를 함께 넣었습니다.

**바로 쓰기: https://trmoo.github.io/bigbungi/**

## 쓰는 법 (3줄)

1. 앱을 열고 왼쪽 탭부터 차례로 — **0 시작 → Ⅰ 통계 기초 → Ⅱ~Ⅵ 검정별 레슨 → Ⅶ 실전 모의 문제**.
2. 노란 빈칸을 채우고 **▶ 실행**(빈칸에서 Enter). 처음 한 번은 파이썬 엔진(약 30MB)을 받느라 20초~1분 걸립니다.
3. 막히면 **💡 힌트**(누를수록 자세히), 시험 직전에는 **📝 한 장 정리**와 **🧭 검정 고르기**를 보세요.

## 인터넷이 없을 때

설명 · 그림 도구 · 확인 문제는 인터넷 없이 됩니다. 파이썬 엔진을 받지 못하면 코드 셀은
**「미리 계산해 둔 결과」**(같은 파이썬으로 정답 코드를 돌린 출력)를 보여 주고, 빈칸은 정답 글자로 채점합니다.
`dist/index.html` 파일 하나를 더블클릭해도 열리고, 인터넷이 되면 그 상태에서도 파이썬이 켜집니다.

## 시험 환경과 다른 점

- 이 실습실은 scipy 1.18 · statsmodels 0.14.6 · pandas 3.0(Pyodide 314.0.7)입니다. 시험 환경의 판은
  공식으로 알려지지 않았습니다. 숫자는 같아도 `np.float64(…)` 같은 **보이는 모양**은 다를 수 있습니다.
- 그래서 레슨은 결과를 차례대로 받아(`stat, p = …`) 반올림하는, 옛 판에서도 되는 방법을 주로 씁니다.

## 개발

```bash
npm install
npm start            # 개발 서버 (앱 폴더의 index.html)
npm test             # 레슨 점검 + node 의 Pyodide 로 다시 돌려 기준 출력과 대조 (약 30초)
npm run build        # 문법·저작권 점검 → dist/index.html 한 파일 → 빌드 점검
npm run data         # 연습용 데이터 다시 만들기 (tools/make_data.py)
npm run golden       # 미리 계산한 결과 다시 만들기 — 레슨 코드를 고치면 꼭 돌릴 것
```
